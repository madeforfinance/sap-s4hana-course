Accounts Payable and Create a new Document Type together can be up to half of your total score, so give these two topics extra practice. Every lesson in this course is hands-on practice for the tasks you will do in the system — it is not about memorising multiple-choice answers. Finish the lessons in order, pass the gate tests, and practise each task in a real SAP system before the exam.

Rules

Course Rules — Please Read First

All lessons from Lesson 2 onward follow these rules
  • Step 1 — Complete the previous lesson. The next lesson will open only when all sections of the previous lesson are marked as read and that lesson's questions have been answered. You cannot move ahead after reading only half a lesson.
  • Step 2 — Pass the gate test. Before opening the next lesson, you must take a gate test of 5 MCQs based on the previous lesson. You pass only with 100% marks — not even with 4 out of 5.
  • Correct answers are never shown. After the test, only your marks will be shown. If you fail, you will only be told: go back and complete previous lesson — then try again.
  • 3 consecutive fails = 1-hour lock. If a candidate fails the gate test in 3 consecutive attempts, that lesson will be locked for 1 hour — during that time the lesson cannot be opened.
  • Admin unlock. If a lesson is locked, you can unlock it with the Admin password.
In Simple Words Just like in school you move to the next class only after passing the previous class — here too, every lesson is a door, and its key is fully completing the previous lesson and scoring 100% in the gate test.
